# 보안과 자료 정책

공개 저장소에는 키·개인 설정·캐릭터 수집 원본·내부 세션 기록을 올리지 않습니다. 테스트 자료는 필요한 파일만 추려 비식별 처리합니다. API 조회는 로컬 개발 서버의 지정된 경로로만 수행합니다.

개발 서버를 공개 운영용 서버로 사용하지 않습니다. 보안 제보에는 공개 Issue 대신 저장소의 비공개 취약점 제보 기능을 사용합니다.
