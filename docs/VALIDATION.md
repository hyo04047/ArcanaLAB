## 공개본 검사

이번 공개 스냅샷에서 실제 실행한 검사·환경·성공·실패·미실행 범위는 [PUBLICATION_CHECKS.json](PUBLICATION_CHECKS.json)에 기록합니다. 문서의 과거 테스트 수나 이전 공개본의 통과 기록을 새 스냅샷의 결과로 대체하지 않습니다. 해당 파일의 날짜와 검사 대상을 함께 확인해야 합니다.

테스트는 모델과 구현의 일관성을 검사합니다. 테스트 통과가 실제 게임 수치·타이밍의 정확성을 보증하지는 않습니다.

## 과거 연구 단계의 검증

2026-10-23까지 로컬 연구 단계에서 다음 범위를 검증했습니다.

- 황후 4개·황제 16개 예시 입력, 같은 계열 126쌍
- 60/180/600초 × 속행 0/20/100% × 뒤운 실패 5/25% × 카드 검산값 4종: 72조건
- 조건·입력별 총 432,000개 결과와 6,048,000개 차이 재구성 대조
- 별도 평균·표준오차 계산과 저장 결과 대조

각 조건은 3개 seed 묶음 × 100회입니다. 432,000은 서로 다른 조건을 포함한 결과 수이며, 모두 독립인 한 모집단의 표본 수가 아닙니다. 카드 검산값과 확률 조건도 실제 게임값 또는 실제 범위라는 뜻이 아닙니다.

이 단계에서는 확률 가정에 따라 일부 비교의 부호가 바뀌었습니다. 개별 변경의 이득을 단순 합산하거나 한 조건의 순위를 다른 조건에 일반화하지 않습니다.

2026-10-29에는 당시 모델의 실제 브라우저에서 세팅 편집·계산·비교·저장·재입력·원본 복귀와 오류/시간 초과 후 복구를 확인했습니다. Node에서 실행한 Worker 경로 검산과 실제 브라우저 사용 확인은 구분해 기록했습니다.

2026-11-01 로컬 연구 모델에서는 전체 **6,312개 테스트·226개 파일**, strict와 별도 build, 대상 경고의 저장 호환·Worker/CLI 재실행을 확인했습니다. 이는 **그 당시 모델과 연구 환경의 과거 검증**이며 이번 공개 스냅샷의 새 통과 수가 아닙니다.

## 마지막 외부 자료 대조와 합성 통제

2026-11-15에는 공개 영상과 사용 시각 기록을 대조했습니다. 서로 다른 전투의 시계·세팅·피해를 합치지 않았고, 사용 횟수를 카드 획득 횟수로 읽지 않았습니다. 같은 전투에서 손패·게이지·쿨의 변화는 확인했지만, 획득을 기여 스킬이나 퀵 드로 하나에 귀속하지 못했습니다.

여러 쿨의 정수 표시는 공통 10% 남은 쿨 감소 후보와 조건부로 양립했습니다. 일관된 표시 규칙·시각 대응·추가 사건 없음 등의 가정 아래 계산한 결과이며, 정확한 감소율이나 유일한 발동 원인의 확인은 아닙니다.

운수의 대상 예약·플래그 소비를 시작에 고정한 합성 엔진 통제에서는 정상 완료 **6쌍**의 중간 준비 상태가 달랐지만 완료 뒤 행동·피해·수급은 같았습니다. 전투 상한으로 잘린 **1쌍**은 따로 기록했으며 취소로 해석하지 않았습니다. 별도 상태전이 반례 **6유형·13분기**도 실제 게임이나 생산 엔진의 취소 구현을 검증한 결과가 아닙니다. 이 숫자는 검사량이지 독립 게임 관측 수가 아닙니다.

## 공개 재현 범위

대용량 연구 원본과 내부 기록은 공개 저장소에 포함하지 않습니다. 위 72조건 연구와 마지막 영상/합성 감사 전체를 이 저장소만으로 재현할 수 있다고 주장하지 않습니다. 공개 저장소에서 재현할 수 있는 범위는 포함된 회귀 테스트·검사 명령, 프리셋 실행, 지원하는 사용자 입력의 실행·저장·재실행·비교입니다.
