# 현재 한계와 다음 과제

ArcanaLAB이 검증하는 것은 **명시한 입력과 가정 아래에서의 계산과 비교**입니다. 실제 게임의 모든 동작이나 최적 장비 구성을 보증하지 않습니다.

| 항목 | 현재 상태 |
|---|---|
| 황제·기사 카드 기본 피해 | 계수 미확인으로 기본 입력이 0입니다. 양의 검산값은 실제 계수가 아닙니다. |
| 일부 발동 확률 | 뒤틀린 운명 실패 25%, 속행 20% 등은 미확인 기본 가정입니다. |
| 마나 | 무제한 마나를 가정합니다. |
| 시전·카드 공급·서버 순서 | 부분 구현이나 미확인 동작이 남아 있습니다. |
| 시작 상태 | 빈 손패, 게이지·스택 0, 스킬 사용 가능, 충전 최대에서 시작합니다. 사전 버프 지정은 지원하지 않습니다. |
| 장비 조합 | 입력 구조 검증이 실제 장착 가능 여부를 보증하지 않습니다. |
| 통계 | 표준오차는 Monte Carlo 변동을 나타내며 게임 수치의 불확실성을 포함하지 않습니다. |
| 화면 | 화면 단위 테스트와 실제 브라우저 전체 사용 흐름 검증을 구분합니다. |

과거 실험 중 고대 코어와 유물 코어의 교환, 보석 효과만 바꾼 입력은 합성 비교입니다. 검산을 통과했다고 실제 장비 교환의 효과가 확정되는 것은 아닙니다.

## 다음 과제

1. 비교하려는 세팅에 영향을 주는 미확인 카드 피해·확률·동작을 좁힙니다.
2. 실제 장착 가능한 같은 계열의 전체 세팅을 구성해 가정 민감도를 확인합니다.
3. 브라우저에서 입력·실행·저장·재현·비교의 전체 사용 흐름을 검증합니다.

절대 DPS를 완전히 일치시키는 일을 모든 비교의 선행 조건으로 두지는 않습니다. 각 비교에 필요한 가정과 영향 범위를 먼저 확인합니다.
