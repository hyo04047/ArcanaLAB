# 검증과 한계

공개본은 전체 회귀 테스트와 저장 결과 재현을 확인합니다. 로컬 연구의 72조건 비교 완료와 실제 게임 정확성은 서로 다른 주장입니다. 일부 카드 피해와 발동 확률, 마나·타이밍 가정이 남아 있습니다.

공개하지 않은 대용량 원본을 근거로, 공개 저장소만으로 전체 연구를 재현할 수 있다고 주장하지 않습니다. 공개 재현 범위와 현재 검사 결과는 아래 문서에 명시합니다.
