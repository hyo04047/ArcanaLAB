# 공개 자료와 출처 정책

## 공개 범위

공개 저장소는 실행 코드, 회귀 테스트, 테스트에 필요한 최소 fixture, 사용·설계·검증 문서를 담습니다. 로컬 연구 저장소의 전체 이력을 이전하지 않고 검토한 스냅샷으로 시작합니다.

다음 자료는 공개하지 않습니다.

- API 키, 토큰, `.env`, 개인 개발 도구 설정
- 캐릭터 조회 원본, 개인을 식별하는 이름·길드·영지·프로필 이미지
- 내부 세션 인수인계, 로컬 절대 경로, 원본 비밀값 검사 보고서
- 수집 웹페이지 전체, 영상·스크린샷 원본, 대용량 실험 중간 산출물

## 회귀 테스트 fixture

`tests/fixtures/`는 기존 테스트가 실제로 읽는 자료를 추려 비식별 처리한 파생본입니다. 캐릭터 식별자와 프로필 이미지·길드·영지 정보는 제거하거나 가상 식별자로 바꾸며, 계산 검증에 필요한 수치와 툴팁은 유지합니다. 이 자료는 현재 캐릭터 정보나 실제 장착 추천으로 사용하지 않습니다.

fixture에 남은 과거 해시·모델 식별값은 당시 비교의 테스트 입력입니다. 비식별 공개 파일 자체의 원본 인증으로 해석하지 않습니다. 공개 파일의 현재 해시는 `docs/PUBLICATION_MANIFEST.json`에서 확인합니다.

## 자료 출처

- [로스트아크 공식 Open API](https://developer-lostark.game.onstove.com/): 공개 캐릭터 전투 정보와 게임 데이터
- [로스트아크 공식 공지](https://lostark.game.onstove.com/News/Notice/List): 패치와 게임 동작 설명
- [Lost Ark Codex](https://lostarkcodex.com/kr/): 공개 게임 데이터의 교차 확인

`data/*.json`의 출처와 `verified` 표시는 항목별 연구 근거이며, 현재 게임에 대한 일괄 인증이 아닙니다. 커뮤니티 자료로만 확인한 효과는 공식 확정값과 구분합니다.

게임 명칭·툴팁 등 제3자 자료의 권리는 원 권리자에게 있습니다. 이 프로젝트는 공식 서비스와 제휴하지 않습니다. 전체 수집물을 재배포하거나 제3자 자료에 자체 오픈소스 라이선스를 부여하지 않습니다.
