# ArcanaLAB 종료 기록

**2026-11-15, 원래 목표가 미완인 상태에서 추가 연구·개발을 중단했습니다.** 프로젝트 소유자의 최종 결정에 따라 현재 코드와 검증 가능한 산출물을 보존합니다. 자동으로 이어지는 조사·구현 계획은 없으며 재개하려면 새로운 결정이 필요합니다. 현재 자료와 비용 조건에서 추가 투자를 멈춘 것이지, 이 문제의 해결이 불가능하다는 증명은 아닙니다.

## 원래 목표와 완료 기준

같은 계열 안에서 여러 축을 바꾼 전체 세팅을 허수아비 전투 조건으로 비교하고, 그 차이를 재현 가능한 계산과 근거로 설명하는 것이 목표였습니다. 카드·치명타·추가 발동 때문에 한 번의 결과가 흔들리는 점을 반복 실험으로 다루려 했습니다.

핵심은 피해 계수의 합을 넘어 **적중 → 게이지·퀵 드로 → 카드 획득 → 카드 사용 → 쿨·버프 → 다음 스킬**의 연결을 검증하는 일이었습니다. 절대 DPS의 완전 일치, 레이드 전체 재현, 자동 최적화는 애초의 필수 완료 조건이 아니었습니다. 그러나 비교 결론을 바꿀 수 있는 이 연결을 끝까지 검증하지 못했으므로 원래 목표를 달성했다고 보고하지 않습니다.

## 남긴 구현 성과

- 스킬·카드·스택·버프·쿨·예약 적중을 처리하는 전투 엔진과 Monte Carlo 반복 실행
- 판정별 난수열과 회차별 차이, 평균 차이·표준오차를 이용한 같은 조건의 비교
- 지원 세팅 선택값 편집, 전체 Build 재생성, 입력 차이 설명과 원본 복귀
- Build·결과 저장, 재실행, 동일 모델·조건 확인과 호환되지 않는 비교 차단
- Web Worker와 CLI 실행, 입력 오류·시간 초과·재시도 복구 경로
- 공개 계수·게이지·스킬 변형 후보의 제한적 연결, 출처·미지원·가정 경고, 기존 저장 호환 보존

이 성과는 실행 가능한 소프트웨어와 모델 내부의 검증 범위입니다. 모든 게임 동작이 정확하거나 계산 순위가 실제 세팅 우열을 보증한다는 뜻은 아닙니다.

## 확인한 것, 가정한 것, 확인하지 못한 것

| 구분 | 내용 |
|---|---|
| 구현·검산으로 확인 | 지정 입력의 실행·저장·재실행 일치, 지원 비교의 조건 검사, 오류 복구, 특정 경계의 엔진 상태 변화 |
| 외부 자료에서 관측 | 같은 전투의 손패·게이지·쿨 표시 변화와 일부 카드/스킬 등록 순서. 자료가 전혀 없었던 것은 아님 |
| 모델의 후보·가정 | 공개 피해 계수, 일부 발동 확률·게이지 단위·타격 시각, 운수 즉시 면제와 충전 처리, 기본 운용 정책 |
| 미확인 | 개별 획득의 기여 스킬·퀵 드로 판정, 완전한 촬영 세팅, 서버 처리와 표시 지연의 분리, 취소·시전 중 입력을 포함한 전체 카드 연쇄 |

공개 자료의 후보를 연결한 현재 입력과 과거의 0·수동 계수 입력은 구분합니다. 새 Lv70 입력의 황제·기사 기본 피해를 일괄 0이라고 설명하는 과거 상태는 더 이상 현재 구현의 설명이 아닙니다. 그렇다고 연결된 후보를 실측으로 검증된 게임 수치로 승격하지도 않습니다.

관측된 운수 대상은 셔플이라는 해석이 유력해졌지만, 실제 초기화가 늦는지 표시만 늦는지는 분리하지 못했습니다. 정상 시전 경로의 합성 비교에서 두 초기화 시점이 같은 후속 결과를 낸다는 사실은 그 공백을 해소하지 않습니다. 실제 취소를 지원하지 않는 엔진에서 전투 시간 제한에 잘린 실행을 취소 실험으로 부르지도 않았습니다.

## 실패와 교훈

초기에는 경고 추가·내부 테스트 확대·단독 피해 민감도 결과를 원래 목표의 진전과 충분히 분리하지 못한 보고가 있었습니다. 이후에는 기존 가이드와 실험 조건을 먼저 확인하고, 실제로 어떤 연결을 재현해야 성공인지 다시 고정했습니다. 내부 검증 수가 많아져도 외부 근거가 부족한 기전은 여전히 미확인입니다.

전체 세팅의 판단에는 연쇄 효과가 필요했습니다. 이보크 피해 보석의 중독 적용처럼 하나의 가정을 바꾸었을 때 일부 비교 순위가 바뀌는 결과는 그 중요성을 보여주었지만, 어느 가정이 실제 게임에 맞는지는 알려주지 않았습니다.

영상의 표시 변화는 사건 구간을 좁히는 데 유용했습니다. 다만 효과·피해·발동 글자가 겹치거나 표시 지연이 있으면 더 많은 프레임만으로 숨은 수급 원인을 복원할 수 없습니다. 사용 횟수를 획득 횟수로 바꾸거나, 직후 카드가 들어왔다는 이유로 바로 앞 스킬의 효과라고 정하지 않아야 합니다.

남은 시간 추정도 자료 확보 뒤의 구현을 전제한 조건부 초안이었습니다. 필요한 자료 조사·측정·대기를 포함한 완료 기간을 약속할 수 있는 상태가 아니었습니다. 기능 확대를 계속하기보다 미완 범위를 명시하고 추가 투자를 멈추는 결정을 내렸습니다.

## 공개본과 로컬 연구 자료

공개본에는 검토한 코드·테스트·비식별 최소 fixture·사용 및 설계 문서를 남깁니다. 개인 설정·인증값·수집 원본·전체 화면 자료·내부 진행 기록·대용량 연구 결과는 로컬 연구 자료로 분리합니다. 공개 저장소에서 접근할 수 없는 원본을 연결하거나 전체 연구의 공개 재현성을 주장하지 않습니다.

공개본만으로 재현할 수 있는 범위는 포함된 검사, 프리셋 실행, 지원 입력의 계산·저장·재실행·비교입니다. 개별 영상 관측과 과거 전체 연구 격자의 재생까지 포함하지 않습니다. 자세한 경계는 [자료 정책](DATA_POLICY.md)과 [검증 기록](VALIDATION.md)에 있습니다.

2026-11-01의 6,312개 테스트·226개 파일 통과는 과거 연구 모델의 기록입니다. 이번 공개 스냅샷의 새 실행 결과는 [PUBLICATION_CHECKS.json](PUBLICATION_CHECKS.json)을 기준으로 확인합니다. 과거 테스트·브라우저 확인·모델 식별값을 새 공개본의 검증으로 대신하지 않습니다.
