# ArcanaLAB

**확률이 개입하는 게임에서, 세팅 변경의 효과를 재현 가능한 실험으로 비교합니다.**

로스트아크 아르카나의 황후·황제 세팅을 각각 같은 계열 안에서 비교하는 TypeScript Monte Carlo 시뮬레이터입니다. 카드, 치명타, 추가 발동처럼 결과를 흔드는 요소를 모델링하고, 두 세팅의 차이를 회차별로 비교합니다.

> 개발 중인 연구 도구입니다. 일부 피해 계수·발동 확률·전투 동작은 가정이며, 결과를 실제 게임 DPS나 장비 추천으로 확정하지 않습니다.

## 해결하려는 문제

룬이나 보석 하나를 바꿔도 카드 획득과 다음 스킬 순서까지 달라질 수 있습니다. 한 번의 전투나 개별 효과의 단순 합만으로는 변경의 이득을 판단하기 어렵습니다. ArcanaLAB은 **전체 세팅을 실행하고, 같은 조건의 반복 결과와 가정을 함께 비교**합니다.

## 구현한 기능

- 스킬·버프·카드·스택·쿨다운을 반영하는 전투 엔진
- 캐릭터 Open API 응답을 계산 입력으로 변환하고 미지원 효과를 경고하는 변환기
- Web Worker에서 계산하는 화면과 같은 엔진을 사용하는 CLI
- 입력·결과 JSON 저장, 불러오기, 재실행 및 설정 차이 설명
- 판정 종류별 난수열과 회차별 차이·평균 차이의 표준오차
- 모델 식별값과 실행 조건을 검사하여 호환되지 않는 결과의 수치 비교 차단

## 빠르게 실행하기

Node.js 24 LTS와 npm을 사용합니다. 프리셋과 저장 파일 비교에는 API 키가 필요 없습니다.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 열고 **프리셋 → 실행**을 선택합니다. 캐릭터 검색은 [시작 안내](docs/GETTING_STARTED.md)의 로컬 API 설정이 필요합니다.

```sh
npm test
npm run build
npm run test:parser
npm run check:publication
```

## 포트폴리오에서 볼 부분

확률적 시스템의 비교 설계, 상태 변화가 연쇄되는 전투 모델, 입력 검증, 결과 재현, 불확실성 표시를 함께 다룹니다. 판정별 난수는 모든 세팅에서 분산 감소를 보장하지 않으며, 통계적 오차와 미확인 게임 수치의 오차를 구분합니다.

공개본은 코드·테스트·비식별 처리한 최소 fixture·정리된 문서로 구성합니다. 개인 설정, 인증값, 수집 원본, 내부 세션 기록, 대용량 연구 산출물은 포함하지 않습니다. 로스트아크의 공식 도구가 아니며 게임 관련 명칭과 데이터의 권리는 원 권리자에게 있습니다.
