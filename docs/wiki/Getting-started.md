# 실행과 비교

Node.js 24 LTS에서 저장소를 clone하고 `npm ci`, `npm run dev`를 실행합니다. 프리셋과 저장 JSON에는 API 키가 필요 없습니다. 캐릭터 검색에만 본인의 로컬 키를 사용합니다.

기준 세팅과 변경 세팅을 같은 시간·반복 수·seed·판정별 난수 방식으로 실행한 뒤 결과 파일을 비교합니다. 비교 화면은 설정 변화, 경고, 조건 호환성, 회차별 수치 차이를 함께 보여줍니다.
