# 검증과 한계

2026-11-15 연구·개발을 중단했습니다. 구현·저장 재현·조건 비교의 성과를 보존하지만, 실제 적중→카드 수급→사용→후속 사이클의 연결 검증은 완료하지 못했습니다. 현 자료 조건에서 추가 투자를 멈춘 결정이며 해결 불가능의 증명은 아닙니다.

새 Lv70 입력의 황제·기사 피해에는 공개 계수 후보가 연결됩니다. 일부 입력이 0이나 수동값인 상태와 구분하며, 공개 후보의 현행 게임 실측 검증을 뜻하지는 않습니다. 발동 확률, 마나·동작·수급·취소·충전 처리에도 가정이 남아 있습니다.

로컬 연구의 72조건 비교와 2026-11-01의 6,312개/226파일 검증은 각각 당시 모델의 과거 기록입니다. 이번 공개본의 새 검사 결과는 별도 JSON에서 확인합니다. 내부 테스트 통과·조건부 관측 양립·실게임 규칙 확정은 서로 다른 검증입니다.

공개하지 않은 대용량 원본을 근거로, 공개 저장소만으로 전체 연구를 재현할 수 있다고 주장하지 않습니다. 공개 재현 범위와 현재 검사 결과는 아래 문서에 명시합니다.
