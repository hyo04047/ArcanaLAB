# 중단 시점의 한계

ArcanaLAB이 검증하는 것은 **명시한 입력과 가정 아래에서의 계산과 비교**입니다. 실제 게임의 모든 동작이나 최적 장비 구성을 보증하지 않습니다.

2026-11-15 추가 연구·개발을 중단했습니다. 아래 항목은 자동으로 진행할 작업 목록이 아니라 중단 시점에 남긴 한계입니다. 결정 배경은 [종료 기록](PROJECT_CLOSEOUT.md)을 참고합니다.

| 항목 | 현재 상태 |
|---|---|
| 황제·황후의 기사 카드 기본 피해 | 새 Lv70 입력·명시적 재생성의 활성 카드에는 공개 계수 후보를 연결합니다. 기준 레벨·절대 피해는 실게임 실측 미검증입니다. 저장된 수동값과 레벨 미확인으로 자동값이 0인 입력은 별도로 안내하며, 옛 저장을 소급 변경하지 않습니다. |
| 일부 발동 확률 | 뒤틀린 운명 실패 25%, 속행 20% 등은 미확인 기본 가정입니다. |
| 마나 | 무제한 마나를 가정합니다. |
| 시전·카드 공급·서버 순서 | 일부 타격·설치·격발 후보를 구현했지만, 관측된 획득의 기여 스킬·퀵 드로 발동과 실제 입력·서버 처리 순서는 충분히 분리하지 못했습니다. |
| 운수·충전·취소 | 현재 즉시 면제 규칙은 모델 가정입니다. 일부 정상 경로에서 종료 후 초기화 후보와 결과가 같아도 게임 규칙의 동일성을 뜻하지 않습니다. 충전 스킬의 운수 처리와 일반 취소·조기 행동 개방은 독립 검증되지 않았습니다. |
| 이보크 중독·보석·게이지 | 기본·변형별 공개 후보와 경고를 연결했지만 현행 중독의 피해 보석 적용, 변형/틱별 게이지와 퀵 드로 귀속에 미확인이 남습니다. 가정 변경에 따라 비교 순위가 달라질 수 있습니다. |
| 시작 상태 | 빈 손패, 게이지·스택 0, 스킬 사용 가능, 충전 최대에서 시작합니다. 사전 버프 지정은 지원하지 않습니다. |
| 장비 조합 | 입력 구조 검증이 실제 장착 가능 여부를 보증하지 않습니다. |
| 통계 | 표준오차는 Monte Carlo 변동을 나타내며 게임 수치의 불확실성을 포함하지 않습니다. |
| 화면 | 과거 실제 브라우저의 비교·저장·복구 흐름을 확인했습니다. 이는 당시 모델·입력 범위의 기록이며, 이번 공개본의 새 브라우저 검증을 대신하지 않습니다. |
| 전체 전투 재현 | 같은 전투의 손패·게이지·쿨을 읽는 자료는 확보했지만, 적중→수급→카드→후속 사이클의 필수 연결을 끝까지 검증하지 못했습니다. |

과거 실험 중 고대 코어와 유물 코어의 교환, 보석 효과만 바꾼 입력은 합성 비교입니다. 검산을 통과했다고 실제 장비 교환의 효과가 확정되는 것은 아닙니다.

## 결과 해석과 재개 경계

절대 DPS를 완전히 일치시키는 일, 레이드 전체를 재현하는 일, 자동으로 최적 세팅을 찾는 일을 모든 비교의 선행 조건으로 삼은 것은 아닙니다. 남은 문제는 비교 결론을 바꿀 수 있는 카드 수급과 후속 행동의 연결을 실제 자료로 검증하지 못했다는 점입니다.

재개는 별도의 결정이 필요합니다. 새로운 자료가 생긴다면 먼저 그 자료가 미해결 연결을 구분할 수 있는지 평가해야 합니다. 새 기능이나 반복 계산을 늘리는 것만으로 이 공백이 해소되지는 않습니다. 현재 공개본의 실행·검사 범위는 [검증 기록](VALIDATION.md)과 [검사 결과](PUBLICATION_CHECKS.json)를 따릅니다.
