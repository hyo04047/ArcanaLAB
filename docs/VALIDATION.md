# 검증 기록

## 공개본 검사

공개 준비 과정에서 설치 의존성, API 프록시 접근 경계, 전체 회귀 테스트, 정적 빌드, 비식별 fixture를 포함한 독립 설치를 확인합니다. 정확한 실행 결과는 `PUBLICATION_CHECKS.json`에 기록합니다.

테스트는 모델과 구현의 일관성을 검사합니다. 테스트 통과가 실제 게임 수치·타이밍의 정확성을 보증하지는 않습니다.

## 이전 연구 단계에서 완료한 비교

2026-10-23까지 로컬 연구 단계에서 다음 범위를 검증했습니다.

- 황후 4개·황제 16개 예시 입력, 같은 계열 126쌍
- 60/180/600초 × 속행 0/20/100% × 뒤운 실패 5/25% × 카드 검산값 4종: 72조건
- 조건·입력별 총 432,000개 결과와 6,048,000개 차이 재구성 대조
- 별도 평균·표준오차 계산과 저장 결과 대조

각 조건은 3개 seed 묶음 × 100회입니다. 432,000은 서로 다른 조건을 포함한 결과 수이며, 모두 독립인 한 모집단의 표본 수가 아닙니다. 카드 검산값과 확률 조건도 실제 게임값 또는 실제 범위라는 뜻이 아닙니다.

이 단계에서는 확률 가정에 따라 일부 비교의 부호가 바뀌었습니다. 개별 변경의 이득을 단순 합산하거나 한 조건의 순위를 다른 조건에 일반화하지 않습니다.

## 공개 재현 범위

대용량 연구 원본과 내부 기록은 공개 저장소에 포함하지 않습니다. 위 72조건 전체 연구를 이 저장소만으로 재현할 수 있다고 주장하지 않습니다. 공개 저장소에서 재현할 수 있는 범위는 전체 회귀 테스트, 프리셋 실행, 사용자가 제공한 전체 입력의 실행·저장·재현·비교입니다.

연구 당시 통과한 검증과 공개본에서 새로 실행한 검증을 분리해 기록합니다. 현재 모델의 미확인 수치는 [현재 한계](LIMITATIONS.md)를 확인합니다.
