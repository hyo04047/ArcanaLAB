# ArcanaLAB Wiki

ArcanaLAB은 같은 계열의 아르카나 세팅을 반복 전투로 비교하는 연구 도구입니다. 구현한 기능, 결과를 읽는 법, 아직 확정하지 않은 가정을 구분해서 안내합니다.

## 처음 방문했다면

1. [프로젝트 소개](https://github.com/hyo04047/ArcanaLAB#readme)에서 목적과 구현 범위를 확인합니다.
2. [실행과 비교](https://github.com/hyo04047/ArcanaLAB/wiki/Getting-started)에서 키 없이 프리셋을 실행합니다.
3. [설계와 결과 해석](https://github.com/hyo04047/ArcanaLAB/wiki/Design-and-results)에서 비교 수치의 의미를 읽습니다.
4. [검증과 한계](https://github.com/hyo04047/ArcanaLAB/wiki/Validation-and-limits)에서 확인 범위를 확인합니다.
5. [보안과 자료 정책](https://github.com/hyo04047/ArcanaLAB/wiki/Security-and-data)에서 공개·로컬 자료의 경계를 확인합니다.

문서의 기준본은 저장소 `docs/`이며, Wiki는 읽는 순서를 안내합니다. 구체적인 구현과 검증 상태는 연결된 저장소 문서를 따릅니다.
